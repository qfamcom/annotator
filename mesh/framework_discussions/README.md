# framework_discussions

This folder is for human-AI discussion notes, tradeoff logs, and framing drafts.

## `artifacts_to_gpt/`
Use this subfolder to collect recently changed framework files for one-time upload/review in ChatGPT.

Suggested flow:
1. Copy only the exact files under review.
2. Add a short note describing intent and questions.
3. Clear old artifacts after review.

## Security Rule
Never put secrets, credentials, private keys, or sensitive production data here.
