# Connector Plan Spec - v0.1.0 Annotation Workflow

## Objective
Define adapter and integration responsibilities for PDF parsing/rendering, annotation overlay, JPG conversion, and ZIP packaging.

## In Scope
- Connector boundaries for:
  - PDF page rendering/parsing.
  - Annotation overlay rendering.
  - JPG conversion per page.
  - ZIP packaging for multi-page JPG export.
- Verification hooks between app flow and conversion adapters.

## Out of Scope
- Provider-specific hard lock-in at plan stage.
- External collaboration integrations.
- Non-document media conversion.

## Integration Points
- App -> document parser/renderer adapter.
- App -> export orchestration adapter.
- Worker -> conversion engine adapter.
- Worker -> artifact packaging adapter.

## Contract Expectations
- Adapters must return deterministic page ordering.
- Conversion interfaces must preserve page identity and annotation version.
- Error interfaces must provide retryable vs non-retryable categorization.

## Verification Strategy
- Contract checks for each adapter input/output schema.
- End-to-end export verification for both PDF and JPG ZIP.
- Failure-path checks for conversion timeout and malformed page payloads.

## Risks and Mitigations
- Risk: third-party converter inconsistency.
- Mitigation: abstraction boundary and golden-file regression suite.

- Risk: ZIP packaging page-order drift.
- Mitigation: strict naming/indexing contract and sorted manifest validation.
