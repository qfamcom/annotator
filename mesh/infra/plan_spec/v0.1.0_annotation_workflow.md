# Infra Plan Spec - v0.1.0 Annotation Workflow

## Objective
Provide infrastructure prerequisites for reliable multi-page PDF annotation and export (PDF/JPG ZIP) with persistence guarantees.

## In Scope
- Storage design for original uploads, annotation payloads, and export artifacts.
- Runtime and worker capacity assumptions for up to 50 MB and 100-page files.
- Environment configuration and secrets boundaries.
- Deployment and observability expectations for v1.

## Out of Scope
- UI and domain-level annotation behavior.
- Third-party vendor lock-in decisions beyond adapter-ready infra expectations.
- Multi-repository or multi-tenant expansion.

## Environment Targets
- `local`: developer workflow and smoke validation.
- `staging`: integration verification for export and persistence behavior.
- `prod`: single production environment for repository-local deployment.

## Resource Requirements
- Compute:
  - API service runtime for upload/annotation/export orchestration.
  - Background worker runtime for render/export jobs.
- Storage:
  - Durable object storage for source files and export outputs.
  - Metadata persistence store for document/page/annotation/export state.
- Network:
  - Private service communication between API and worker components.
  - Controlled egress for optional conversion integrations.
- Secrets/config:
  - Storage credentials.
  - Signing keys/tokens for upload/download flow.
  - Environment-level limits (max file size 50 MB, max pages 100).

## Reliability and Performance Constraints
- Annotation persistence completeness target is 100% for annotated pages.
- Export success rate target is >= 99.0%.
- Infrastructure must tolerate concurrent processing without partial-write states.

## Observability Requirements
- Logs:
  - Upload, annotation save, export request, export completion/failure lifecycle.
- Metrics:
  - Export success rate.
  - Export duration.
  - Annotation save failure rate.
  - Storage write/read failures.
- Alerts:
  - Export success rate below target.
  - Persistent storage errors.

## Risks and Mitigations
- Risk: large multi-page jobs cause timeouts.
- Mitigation: asynchronous worker queue and resumable job state.

- Risk: partial annotation writes create page drift.
- Mitigation: transactional page-save semantics and versioned annotation snapshots.

- Risk: orphaned exports consume storage.
- Mitigation: lifecycle retention policy with cleanup jobs.
